# Changelog

## [Unreleased] — TLA Shop demo (#4)

The playground became a small demo shop: browse → add to cart → cart → checkout → login → order placed.

### Added
- `remote-catalog` (port 3020): product list/detail from DummyJSON; exposes `./ProductsApp` and renders its own `<Routes>`.
- `remote-cart`: `CartBadge`, `CartPage` and the `cartStore` (consumed by the host and the catalog).
- `remote-user`: `LoginForm`, session store and `useCurrentUser` with a mock login (`jane.doe@example.com` / `password123`).
- Host: guarded `/checkout` (`RequireAuth`), `/login`, `/products/*`, user menu.
- "Show app boundaries" switch that outlines and labels every region owned by a remote (hidden below 640px).
- Shared design tokens (`tokens.css`, one copy per app).

### Changed
- Cart and session state live on `globalThis` and persist to `localStorage`, so the host and every remote see the same state.
- "Retry" on a failed remote reloads the page (Module Federation cannot re-import a remote after a failed load).
- Remote types are generated by the MF plugin; hand-written `declare module` blocks removed.
- Converted to a pnpm workspace with a root `pnpm dev` / `pnpm build`; per-app lockfiles replaced by one.

### Removed
- `CartWidget` (replaced by `CartBadge` / `CartPage`) and the host `UserPage`.
